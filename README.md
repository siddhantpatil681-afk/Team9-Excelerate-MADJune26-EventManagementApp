# Event Management App
## Team 9 - Excelerate

### Description
A Flutter-based mobile application that enables users to browse events, view event details, register for events, and manage their participation efficiently in a simple and organized way.

### Features
- Login & Registration
- Browse Events
- View Event Details
- Register for Events
- User Profile
- Feedback

### Technologies
- Flutter
- Dart
- GitHub
